    MODEL DISCLOSURE / v1.0
    Technique
    Character n-gram TF-IDF + logistic regression
    Languages
    English / Traditional Chinese; mixed text experimental
    Training data
    Synthetic scenarios; no personal inbox messages
    Evaluation
    Group-disjoint held-out synthetic examples
    Hosting
    Static HTML / CSS / JavaScript
    Limitations
    False positives and false negatives; concept drift; no sender verification; no live URL lookup

    Built with AI assistance and documented as such. This is a decision-support prototype—not an automated fact checker.
